# سیگنال‌نما

پروژه اندروید استودیو آماده برای ساخت ویجت نمایش قدرت سیگنال اینترنت سیم‌کارت روی صفحه اصلی اندروید.

## مشخصات پیکربندی فعلی
- نام پکیج: `com.signalnama.widget`
- اندازه پیش‌فرض ویجت: `2x2` (2x2 خانه لانچر)
- حالت سیم‌کارت: دو سیم‌کارت همزمان
- تم انتخابی: `material-dark`

## مراحل ساخت فایل نصبی (APK)
1. این پوشه را در **Android Studio** باز کنید (`Open > Select Folder`).
2. صبر کنید تا Gradle Sync کامل شود.
3. از منوی بالا گزینه `Build > Build Bundle(s) / APK(s) > Build APK(s)` را بزنید.
4. فایل `app-debug.apk` را روی گوشی اندرویدی خود نصب کرده و مجوزهای `READ_PHONE_STATE` و `ACCESS_COARSE_LOCATION` را تایید کنید (اندروید برای خواندن dBm دکل مخابراتی نیازمند این دو مجوز است).
5. در برنامه روی دکمه **«افزودن ویجت به صفحه اصلی گوشی»** بزنید یا از لانچر گوشی ویجت را اضافه کنید.
